  • Spotify Clone

    HTML, CSS, JavaScript, React

    An interactive, single-page music streaming application clone that replicates the core frontend functionalities of Spotify. This project implements a fully operational web audio architecture, allowing users to browse music catalogs, dynamically filter categories, and control music playback via real-time play, pause, skip, and volume functionalities. By leveraging local state management and browser storage, it handles dynamic data binding for user playlists, demonstrating strong state-driven UI development and event-handling proficiency.

  • Youtube Clone

    HTML, CSS, JavaScript, React

    A fully responsive YouTube homepage replication designed to demonstrate advanced UI layout control, component structuring, and modern styling techniques. Built using a semantic component-based approach, the application features a multi-sectional grid layout for video feeds, a collapsible navigation sidebar, and dynamic interactive elements like fluid hover states and a functional search navbar. This project highlights a strong command of modern CSS architecture, pixel-perfect design accuracy, and cross-browser responsiveness to deliver a highly intuitive and native-feeling user experience

  • Movie Search Website

    HTML, CSS, JavaScript, React

    Built a dynamic, responsive movie search application that allows users to seamlessly browse, filter, and discover films in real-time. Leveraging a third-party movie API, the project highlights advanced state management and asynchronous data fetching to deliver instantaneous search results. I prioritized performance and user experience by implementing optimized image handling via responsive srcset configurations, lazy loading, and a clean, modern UI built with semantic HTML and CSS Grid.
